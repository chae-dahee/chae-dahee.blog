# 블로그 글 이관 가이드

기존 글을 `content/posts`로 옮겨 정리할 때 따르는 작업 기준이다.

## 작업 단계

1. 문서 정보를 수정한다.
2. 맞춤법과 문장 흐름 등 내용을 정돈한다.
3. 보강할 내용과 틀린 내용을 반영한다.

내용 정리를 먼저 끝내고, 검토와 보강은 따로 요청할 때 진행한다. 확인이 필요한 사항은 바로 수정하지 않고 다음 작업에서 질문한다.

## 문서 정보

title과 date는 직접 지정한 값을 사용한다. excerpt와 tags는 본문 내용에 맞게 작성한다.

- tags는 띄어쓰기 없이 붙여 쓴다.
- 파일명에는 `.md` 확장자를 붙이고, 오타가 있으면 수정한다.

## 내용 정돈

가독성, 맞춤법, 설명의 적합성을 기준으로 수정한다. 이때 원문 문체를 반드시 유지하고, 기존 문서의 설명 구성을 무너뜨리지 않는다.

- 문장 끝의 `~한다`, `~이다`, 명사형 종결은 수정하지 않는다.
- `~입니다` 같은 존칭 종결만 수정한다.
- `크게 N가지다`, `다음과 같이 나뉜다`처럼 뒤 내용을 예고만 하는 문장을 쓰지 않는다.
- 약어는 대문자로 표기한다.
- 첫 제목을 제거하고 하위 제목을 한 단계씩 올린다.
- 제목의 이모지는 유지한다.
- `-` 기호는 한국어 문서 기준으로 병렬 항목에만 쓰고, 설명 문장에는 붙이지 않는다.

## 보강과 정정

보강하는 내용도 원문 문체에 맞춰 작성한다. 정확한 수치가 아니라 의미를 전달하는 설명(예: IPv4 : IPv6 = 99 : 1 정도의 체감 비율)은 수치 검증이나 웹 검색 대상으로 삼지 않는다.

## 이미지

원본 이미지는 주석으로 남겨 두고, 이미지 파일은 직접 내려받아 추가한다.

- 추가된 이미지는 내용을 검토한 뒤 적합한 위치에 배치한다.
- 이미지 파일명은 영문으로 수정한다.
- 텍스트로 표현할 수 있는 이미지는 텍스트로 대체한다.
- 대표 이미지는 직접 지정한다.
- 출처는 이미지 아래에 기울임으로 작성한다.
- 추정한 출처나 대학 교재·강의자료 출처는 작성하지 않는다.
